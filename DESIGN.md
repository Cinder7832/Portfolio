# Apple-Inspired Portfolio Design

## Direction
Use a photography-first, Apple-inspired portfolio style: quiet UI chrome, large confident type, flat light/dark sections, and a single blue accent for every interactive action.

## Tokens
- Canvas: `#ffffff`
- Parchment: `#f5f5f7`
- Ink: `#1d1d1f`
- Muted ink: `#7a7a7a`
- Hairline: `#e0e0e0`
- Action blue: `#0066cc`
- Action blue hover/focus: `#0071e3`
- Dark tile: `#272729`

## Rules
- Use `system-ui, -apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", sans-serif`.
- Headlines use weight `600` with tight, calm spacing.
- Body copy is short, 17px where possible, and never overly explanatory.
- Interactive elements use blue pills or blue text links.
- Avoid decorative gradients and heavy UI shadows.
- Use flat full-width light/parchment/dark sections to create rhythm.
- Image cards can carry the only meaningful shadow, similar to product photography resting on a surface.
- Keep nav minimal, frosted, and low contrast.
